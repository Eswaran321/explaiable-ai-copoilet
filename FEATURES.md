# AI Content Analyzer Pro - Features Guide

## Overview

AI Content Analyzer Pro is a full-stack Next.js application that leverages advanced AI models, real-time database integration, and modern UI design to detect AI-generated content, perform intelligent searches, and provide comprehensive analytics.

---

## 🔍 Feature 1: AI Content Detection

### What It Does
Analyzes any text content and determines if it was generated by AI or written by humans, providing a confidence score and detailed analysis.

### How to Use
1. Click on the **"AI Detection"** tab in the navigation
2. Paste or type your content in the text area
3. Click **"Analyze Content"**
4. Wait for the AI analysis (2-5 seconds)
5. View detailed results with confidence score

### What You Get
- **Confidence Score**: 0-100% indicating likelihood of AI generation
- **Detection Type**: Classification (human, ai_generated, mixed)
- **Status Badge**: Clear indicator if content is AI-generated
- **Key Indicators**: List of specific patterns that suggest AI origin
- **Detailed Explanation**: Why the system thinks it's AI or human
- **Visual Progress Bar**: Real-time confidence visualization

### Under the Hood
- Uses Groq API (Mixtral 8x7B model)
- Fast inference (~2-5 seconds)
- Analyzes writing patterns, structure, and style
- Stores all analyses in Supabase for history
- Row-level security ensures privacy

### Use Cases
✓ Verify if student essays are original
✓ Check social media posts for authenticity
✓ Verify article authorship
✓ Detect AI-generated content in emails
✓ Quality assurance for content creation

### API Details
```
POST /api/detect
Content-Type: application/json

{
  "content": "Text to analyze",
  "userId": "user_12345"
}

Response:
{
  "success": true,
  "result": {
    "confidence_score": 75,
    "detection_type": "ai_generated",
    "is_ai_generated": true,
    "analysis": {...}
  }
}
```

## 🌐 Feature 2: Advanced Search Engine

### What It Does
Searches the web and returns AI-ranked results with relevance scoring and accuracy metrics.

### How to Use
1. Click on the **"Advanced Search"** tab
2. Type your search query
3. Press Enter or click **"Search"**
4. View results with relevance scores
5. Click external links to visit sources
6. Track accuracy in analytics

### What You Get
- **5-8 Relevant Results**: Curated search results
- **Relevance Scores**: 0-100% for each result
- **Source Type**: Article, video, research, news classification
- **Snippets**: Preview text for each result
- **Direct Links**: One-click access to sources
- **Accuracy Metric**: Overall search accuracy percentage

### Result Components
```
Title
└─ Source URL
└─ Snippet (2-3 sentences)
└─ Relevance Score (0-100%)
└─ Source Type (badge)
```

### Under the Hood
- Powered by Groq AI for result generation
- Intelligent ranking algorithm
- Caches frequently searched queries
- Stores search history in database
- Calculates accuracy dynamically

### Use Cases
✓ Research topics quickly
✓ Find information with verified sources
✓ Compare search results quality
✓ Track search trends over time
✓ Educational research support

### API Details
```
POST /api/search
Content-Type: application/json

{
  "query": "search term",
  "userId": "user_12345"
}

Response:
{
  "success": true,
  "results": [
    {
      "title": "Result Title",
      "url": "example.com",
      "snippet": "Preview text...",
      "relevance_score": 92,
      "source_type": "article"
    }
  ],
  "accuracy": 85
}
```
